# Pharmacy POS System

A Pharmacy Point of Sale and Inventory Management System developed using:

- PHP
- MySQL
- Bootstrap 5
- Python

---

## Requirements

- XAMPP
- PHP 8+
- MySQL 8+
- Python 3.12+
- VS Code
